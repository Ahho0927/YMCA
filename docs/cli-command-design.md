# YMCA CLI 명령 체계 개편 계획

- 상태: 구현 반영 v0.8 — 강의명 다운로드 폴더와 개별 다운로드 실패의 경고 처리 추가. 후속 기능은 6번에 명시한다.
- 작성: 2026-10-16 · 최근 수정: 2026-10-22
- 목적: 실제 YNU LMS 화면의 정보 구조와 터미널에서 자주 하는 작업을 연결한다.
- 진행 방식: 이 파일에서 제안·결정·보류 사항을 갱신한 뒤 합의된 범위를 구현한다.

## 1. 이번 논의의 범위

확정된 방향은 CLI 자체의 사용성을 우선한다는 것이다. TUI와 AI agent/MCP 연동은 향후 확장으로 두고 이번 개편에 포함하지 않는다. 현재 인증·HTML 파서·다운로드 기능은 명령 체계를 논의하는 기반으로 활용한다.

사용자의 구현 요청에 따라 확정한 명령 이름·계층·강의 선택·자료 다운로드 흐름을 구현했다. 명령 변경과 JSON 데이터 변경은 구분하여 기존 리소스 JSON 필드를 유지한다.

## 2. HTML에서 확인한 정보 구조

다음은 추측한 기능이 아니라 로컬 캡처와 현재 파서에서 확인한 사실이다. 원본 HTML의 개인정보와 세션 값은 이 문서에 복사하지 않는다.

| 화면 | 확인한 정보·동작 | 명령 설계에 주는 의미 |
|---|---|---|
| 대시보드 | 사용자, 이전 로그인, 최신 공지, Topics, 학년도·학기 선택, 요일별 강의 카드 | 공통 홈 페이지를 내부 데이터 소스로 사용하되 CLI는 프로필·Topics·공지·강의 명령으로 나눈다. |
| 강의 상세 | 강의명·7자리 코드, 회차별 설명·실시일·출결, 회차 안의 여러 교재 | 강의와 교재 사이에 ‘수업 회차’라는 탐색 단위가 있다. |
| 강의 상세의 표시 탭 | 수업별·교재별·상태별 표시 | 화면별 명령을 모두 복제하기보다는 같은 데이터를 다른 기준으로 조회할 수 있게 한다. |
| 교재 행 | 자료·레포트·시험 등 종류, 교재 ID, 제목, 공개 기한, 상태 | 파서에서는 종류를 구분한다. 통합 교재 목록 명령은 제공하지 않는다. 공개 기한과 제출 마감은 별도 정보다. |
| 자료 상세 | 교재 안에 첨부파일·설명이 존재하고 파일 ID가 별도로 있다. | ‘자료 교재 하나’와 ‘파일 하나’는 다른 다운로드 단위다. |
| 레포트 상세 | 제출 기간, 제출 상태, 과제문, 답안·제출용 폼 | 조회할 때는 과제 정보만 읽는다. 답안·제출 동작은 이번 범위에 추가하지 않는다. |
| 공지 목록·상세 | 공통 공지함, 분류·발신자·일시·미독 여부, 관련 강의명, 본문·첨부파일 | 공지는 독립된 대상이다. 목록은 AJAX와 페이지 이동을 처리해야 한다. |
| 실라버스 | 대시보드에는 없는 7자리 코드를 강의 상세에서 얻어 공개 사이트를 조회 | 강의 ID로 조회할 수 있게 유지하되, 내부 ID와 강의코드를 구분한다. |

개념적인 탐색 구조는 다음과 같다.

```text
대시보드
├── 강의
│   ├── 강의 정보·실라버스
│   └── 수업 회차
│       └── 교재
│           ├── 자료 → 설명·첨부파일
│           ├── 레포트 → 과제문·제출 마감·제출 상태
│           └── 시험 등 → 목록에서 종류·상태 확인
├── 공지 → 본문·첨부파일
└── Topics → 시스템 안내
```

근거로 확인한 캡처 유형: `_lms_homeHoml_doIndex-*`, `_lms_homeHoml_doLinkKougi-*`, `_lms_corsColl_invokeLoad-*`, `_lms_corsColl_doLinkKyozaiTitle-*`, `_lms_infrInfl_doIndex-*`, `_lms_infrInal_index-*`, `_lms_infrInfr_doIndex-*`.

주의할 점:

- `KOG…` 내부 ID와 `801105Z` 형태의 7자리 강의코드는 서로 다른 식별자다.
- 같은 강의명이 여러 ID로 존재한다. 이름만으로 첫 번째 강의를 자동 선택하면 안 된다.
- 회차는 현재 이름·날짜로 파싱하지만 안정적인 회차 ID는 아직 모델에 없다.
- 공지 목록에는 강의 ID 필터가 확인되지 않았다. 관련 강의명만으로 ID를 확정할 수 없다.
- 시험 행의 공개 기한만으로 실제 응시 마감이나 미제출 과제 여부를 단정할 수 없다.
- 메뉴에 보이는 성적·출석·FAQ 등의 기능이 모두 CLI에 구현된 것은 아니다.

## 3. 개편 전 명령에서 확인한 문제 — 논의 배경

1. `courses show`가 강의 정보, 회차, 모든 교재를 함께 출력한다. 강의 구조 파악과 특정 자료 찾기를 나눌 필요가 있다.
2. LMS의 ‘교재’는 자료·레포트·시험의 상위 개념이다. CLI에서는 별도 `items` 명령을 추가하지 않고 자료·레포트를 직접 탐색한다.
3. `assignments`는 실제로 레포트만 다룬다. 사용자는 이름을 보고 시험이나 다른 과제까지 포함한다고 기대할 수 있다.
4. `materials <id> download`는 교재에 속한 파일들을 받는다. 특정 첨부파일 하나를 고르는 명령은 없다.
5. `--course`가 일괄 등록되어 `courses list`에서는 의미 없이 수용되고 `notices`에서는 거부된다. 유효한 명령에만 옵션이 나타나야 한다.
6. 긴 내부 ID를 반복 입력해야 한다. 사람이 강의를 선택하는 방법을 별도로 논의해야 한다.
7. 홈 화면에 보이는 Topics는 목록·본문을 따로 탐색하는 명령이 없다.
8. 진단용 `--capture-dir`가 일상 명령의 도움말에도 노출된다. 진단 기능을 별도로 모으는 방안을 검토한다.

## 4. 확정 방향: 강의를 먼저 지정하고 대상·동작 선택

사용자 제안에 따라 `ymca courses <course> <resource> [<id>] <action>` 구조로 정리한다. 강의 안의 명령은 강의 인자를 먼저 받고, 대상 이름은 `materials`, `reports`처럼 복수형으로 통일한다. 목록·상세는 단복수가 아니라 `list`, `show` 동작으로 구분한다. 개별 자료·레포트·공지 ID는 각 대상 이름 바로 뒤에 배치하고, 그 뒤에 동작을 지정한다. 이 구조로 CLI를 변경했다.

`items`는 LMS에서 자료·레포트·시험을 묶는 ‘교재’ 목록을 뜻했으나, 사용자가 별도 목록의 필요성이 없다고 보아 개편안에서 제외한다. 내부 파서는 종류와 회차 정보를 보존하고 각 대상 목록에서 활용한다. 시험 상세·응시 명령은 이번 개편에 추가하지 않는다.

### 강의 선택 — 확정

- `<course>`에는 `KOG…` 내부 ID·7자리 영숫자 강의코드 또는 전체 선택 `'*'`를 받는다. 사용자 지정 별칭은 지원하지 않는다.
- 코드 매핑이 없으면 대시보드에 나온 강의 상세를 자동 조회하여 내부 ID와의 연결을 저장한다. 내부 ID로 접근할 때 코드 매핑 전체 조회를 강제하지 않는다.
- 매핑은 계정·학년도별로 구분한다. 저장된 후보는 현재 대시보드의 강의 범위와 대조하고 오래된 후보만으로 강의를 선택하지 않는다.
- 같은 코드에 여러 내부 ID가 연결되면 후보를 표시하고 내부 ID로 지정하도록 한다. 첫 번째 결과를 자동 선택하지 않는다.
- 조회 실패로 코드 매핑이 불완전하면 ‘없는 코드’라고 단정하지 않는다. 일부 상세 조회 실패와 실제 미일치를 구분한다.
- 조회 진행과 오류는 stderr에 출력하며 코드 매핑 저장에 SID나 쿠키를 포함하지 않는다.

### 구현한 명령

강의 상세도 `courses <course> show`, 실라버스도 `courses <course> syllabus`로 배치해 강의 인자 위치를 맞춘다. 아래는 구현한 명령이다. 후속 후보는 6번에 분리했다.

| 대상 | 구현한 명령 | 역할·변경점 |
|---|---|---|
| 기본 실행 | `ymca` | 네트워크 요청 없이 도움말 표시 |
| 프로필 | `ymca profile show` | 이름·역할·이전 로그인 시각. JSON에 요청 검증 여부 포함 |
| 시스템 안내 | `ymca topics list` | LMS 홈 페이지에 노출된 시스템 안내의 날짜·제목·ID |
| 강의 목록 | `ymca courses list` | ID·이름·요일·교시·학기 표시 |
| 강의 상세 | `ymca courses <course> show` | 사람용 출력은 강의 정보·회차 설명·출결·종류별 개수, JSON은 기존 전체 상세 유지 |
| 자료 목록 | `ymca courses <course> materials list [--lesson <name>]` | 회차별 자료 표시. 회차 이름으로 조회 범위 제한 가능 |
| 자료 상세 | `ymca courses <course> materials <material> show` | 설명과 첨부파일 ID·이름 표시 |
| 자료 다운로드 | `ymca courses <course> materials <material> download '*'` | 해당 SRY 묶음의 모든 첨부파일 다운로드. 파일 인자 생략 시에도 전체 파일 선택. 기존 `--all`은 호환 별칭 |
| 단일 파일 | `ymca courses <course> materials <material> download <file-id>` | 특정 첨부파일만 다운로드. 기존 `--file`도 호환 별칭 |
| 회차 전체 자료 | `ymca courses <course> materials '*' download --lesson <name>` | 지정 회차의 모든 SRY 자료 묶음 다운로드 |
| 강의 전체 자료 | `ymca courses <course> materials '*' download` | 해당 강의의 자료를 강의·회차별 폴더로 다운로드 |
| 레포트 목록 | `ymca courses <course> reports list` | 실제 제출 마감·제출 상태 조회 |
| 레포트 상세 | `ymca courses <course> reports <report> show` | 과제문·제출 기간·제출 상태 조회 |
| 실라버스 | `ymca courses <course> syllabus` | 현재 `--url-only`, `--year` 유지 |
| 공지 | `ymca notices list`, `ymca notices <notice> show` | 독립된 공지함. 지원되지 않는 `--course` 제거 |
| 인증 | `ymca auth login / status / logout` | 유지 |
| 세션 유지 | `ymca keepalive enable / disable / status / run` | 유지 |
| 셸 지원 | `ymca completion <shell>`, `ymca help` | 유지 |

독립된 `courses download`, 단수형 `material`·`report`, 통합 `items` 명령은 새 체계에 두지 않는다. 개별 자료 다운로드는 `materials <id> download`, 강의·회차 전체 다운로드는 `materials download --all`로 구분한다. 공지 첨부파일 다운로드는 자료와 다른 대상으로서 이번 구현에서 보류했다. Topics 요약은 `topics list`로 분리했다. `dashboard`는 제거 안내만 반환한다.

`materials list`는 강의 화면을 기반으로 표시한다. `reports list`는 실제 레포트 상세를 추가로 읽어 제출 마감까지 보여준다. 공개 기한을 제출 마감으로 해석하지 않으며 추가 요청 비용을 도움말에 명시한다. 회차는 별도 `items` 없이 자료·레포트 목록의 구분과 자료의 `--lesson` 필터로 활용한다.

### 사용 흐름 예시

```sh
ymca profile show
ymca topics list
ymca courses list
ymca courses 801105Z show
ymca courses 801105Z materials list
ymca courses 801105Z materials MATERIAL_ID show
ymca courses 801105Z materials MATERIAL_ID download '*' --output ./downloads
ymca courses 801105Z materials MATERIAL_ID download FILE_ID
ymca courses 801105Z materials '*' download --lesson "第１回"
ymca courses 801105Z materials '*' download
ymca courses 801105Z reports list
ymca courses 801105Z reports REPORT_ID show
ymca courses 801105Z syllabus
```

## 5. 전체 강의 조회와 명령 일관성

강의 안에서 하는 작업은 4번의 구조로 모은다. 이전 문법을 별도 실행 경로로 유지하지 않는다. 자료·레포트·공지의 `show <id>` 및 자료의 `download <id>`는 새 순서를 안내하고 종료 코드 `2`를 반환한다. 이전 최상위 `materials`·`assignments`는 숨겨진 안내 명령으로 두고, 새 문법 예시와 종료 코드 `2`를 반환한다. 예전 `courses show <id>`·`courses syllabus <id>` 순서도 강의 인자가 먼저라는 안내와 종료 코드 `2`를 반환한다.

전체 선택은 ID 자리의 리터럴 `'*'`로 명시한다. `courses '*'`는 현재 대시보드의 학년도·학기에 보이는 고유 강의들만 선택한다. `courses '*' reports list`는 전체 강의 레포트 요약, `courses '*' reports '*' show`는 전체 레포트 상세다. `materials '*' show`·`notices '*' show`도 모든 해당 상세를 조회한다. 암묵적으로 범위를 넓히지 않는다.

모든 `'*'`는 따옴표 또는 `\*`로 셸 확장을 막아야 한다. `SRY*` 같은 부분 패턴은 지원하지 않는다. 기존 `--all`·`--file`은 호환 별칭으로 유지한다.

`materials '*' download`는 강의 전체, `materials '*' download --lesson <name>`는 회차 전체, `materials SRY_ID download '*'`는 한 묶음 전체다. `materials SRY_ID download FILE_ID`는 파일 하나다. 파일 선택 인자를 생략하면 전체 파일이 기본값이다. `courses '*' materials '*' download '*'`로 모든 현재 강의의 자료를 받을 수 있다.

위치 파일 인자와 `--file`을 함께 쓰지 않는다. 특정 파일 ID와 `--all`도 함께 쓰지 않는다. `materials '*'`에서는 `--lesson`을 지원하고, 구체적인 SRY ID와 회차 이름은 함께 사용하지 않는다. ID 없는 기존 `materials download --all`도 계속 지원한다.

회차 선택은 `courses <course> show`에 표시되는 정확한 이름을 사용한다. 확인한 HTML의 `jyugyoHiddenId`는 빈 공통 폼 필드였으며 안정적인 회차별 ID는 검증되지 않았다. 회차 순번을 영구 ID로 만들지 않는다. 이름이 없거나 중복되면 파일 조회·다운로드 전에 실패한다. 정상적으로 존재하지만 자료가 없는 회차는 빈 결과로 성공한다. 자료 목록에도 같은 `--lesson` 필터를 제공한다.

강의·회차 전체 다운로드는 `강의명/회차명/` 하위 디렉터리를 사용한다. 경로에 쓸 수 없는 문자를 정리한 뒤 같은 이름이 되면 `강의명 (1)`처럼 구분한다. 현재 대시보드 전체의 고유 강의를 내부 ID 순으로 정렬해 이름을 배정하므로 한 강의만 ID·코드로 선택해도 전체 선택과 같은 폴더를 사용한다. 기존 폴더는 재사용하고 파일 충돌은 기존 접미사 규칙으로 보존한다. 한 강의·한 SRY를 고르면 파일은 `--output`에 직접 저장한다. 강의 또는 자료가 `'*'`이면 강의명/회차명 하위 폴더로 나눈다. 전체 강의 다운로드의 결과 행에는 `course_id`를 포함한다.

첨부 없는 텍스트 자료, 자료 상세 조회 실패, 개별 파일 다운로드 실패는 ID·사유를 포함한 stderr 경고로 남기고 건너뛴다. 전체 강의 다운로드 중 한 강의를 읽지 못해도 같은 방식으로 다음 강의를 처리한다. 이 경우 JSON은 `warning` 필드를 사용하며 성공 파일과 결과를 보존하고 종료 `0`을 반환한다. 잘못된 인자, 정상 조회 후 확인된 명시 ID 미존재, 회차 미존재·중복, 최초 세션·강의 목록 조회 실패는 오류다. 인증 만료·취소는 후속 요청을 중단하고 오류로 반환한다. 인증 만료는 종료 `3`과 `error` 기록을 유지한다.

프로필·Topics는 여전히 같은 홈 HTML을 내부적으로 한 번씩 요청하지만 통합 대시보드는 출력하지 않는다. 기본 `ymca`는 도움말만 표시하고 `dashboard`는 새 명령 안내와 종료 코드 `2`를 반환한다. 인증·세션 유지 상태는 기존 `auth status`·`keepalive status`에서 확인한다. `profile show --file`과 `topics list --file`로 저장 HTML을 오프라인 파싱할 수 있으며 세션을 가져오지 않는다.

현재 Cobra 기반 구현에서는 위치 인자인 `<course>` 및 자료·레포트·공지 ID 뒤에도 하위 명령이 이어지는 구조를 명시적으로 처리했다. 강의 선택 인자를 분리하고 정적인 하위 명령 트리로 전달하는 라우팅을 구현했으며, 도움말·completion에서도 같은 순서를 지원한다. 잘못된 강의 인자나 하위 명령을 로그인·네트워크 요청보다 먼저 검사한다.

## 7. 구현 시 유지할 기준과 검증

다음 기준을 유지하며 구현하고 회귀 테스트에 반영했다.

- `--json`의 결과 데이터는 stdout, 진행·오류·호환성 안내는 stderr로 유지한다.
- 기존 종료 코드와 로그인·2차 인증 흐름을 유지한다.
- 명령 이름을 바꾸는 작업과 JSON 필드 구조를 바꾸는 작업은 구분한다. 이번에는 JSON 필드 구조를 유지하고 명령 문법만 변경했다.
- 지원되지 않는 옵션을 도움말에 노출하거나 조용히 무시하지 않는다.
- 자료 교재·첨부파일·레포트·시험 식별자를 혼동하지 않는다.
- 명령 도움말과 completion에 같은 명령·옵션 구조를 반영한다.
- 대시보드·자료 목록 표시만으로 모든 레포트 상세나 파일을 가져오지 않는다. 코드 매핑 조회는 강의 상세까지만 읽는다.
- 와일드카드 조회 JSON은 성공한 항목들의 평평한 배열이며 빈 선택은 `[]`다. 단일 ID 조회 형식은 유지한다. 일부 조회 실패는 성공 결과를 출력하고 stderr 오류·비정상 종료로 보고한다. 다운로드의 개별 실패는 성공 파일과 `warning` 기록을 보존하고 정상 종료한다. 인증 만료·취소 시 후속 요청을 중단한다.
- 회귀 검증: 기본 실행의 오프라인 도움말·dashboard 제거 안내, 프로필/Topics 분리·빈 목록·로그인 HTML 거부, 강의/회차/SRY별 전체 다운로드, 회차 미존재·중복·빈 자료, 잘못된 범위 조합, 강의 인자 뒤 하위 명령의 라우팅·도움말·completion, 내부 ID·코드 동등 동작, 매핑 없는 첫 조회·캐시·중복 코드·일부 실패, 중복 강의명, 빈 강의, 회차별 교재, 파일 여러 개, 공지 첨부, 마감 없음·24:00, JSON, 이전 명령 안내, 유효하지 않은 옵션.
- 원본 캡처와 계정 정보는 계속 비공개로 보관하고 테스트에는 비식별 fixture를 사용한다.
